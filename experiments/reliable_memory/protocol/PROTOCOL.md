# Reliable memory: frozen follow-up protocol

Baseline main: `8533eb65d1f8dc9bf3f91194ed97665f294e17c4`. This experiment follows the merged bake-off; it does not reopen its held-out set or replace its primary results. All prior fixtures/evidence are hash-registered in `preserved.json`.

## Inputs and review

Two immutable public MIT Writ revisions, twelve architecture documents, complete paragraph passages (70–1600 characters), 60 distinct section families and 12 unknown controls. Development and held-out partitions use disjoint files. Four positive tasks per partition use the older revision; those tasks receive only that snapshot. Natural-language tasks and explicit source/evidence requests are separate tracks. All arms get identical visible records, requests and complete JSON budgets. The original weighted/Phase 3 commands remain independent controls.

These are model-authored, unreviewed labels. A section question can admit other relevant passages; exact gold-paragraph delivery is a provisional proxy, not a proof of complete answers. `review/labels.csv` contains complete passages, exact revisions and fields for an actual reviewer. No reviewer or reviewed flag is invented. This sample is broader than the bake-off but still architecture documentation, not independently adjudicated real coding outcomes. Live source histories with contradictions/retractions are tested as recorded local scenarios, not fabricated public facts.

## Pre-registered behavior and comparison

Zero development tuning trials. Fixed settings in `settings.json`; no parameter selection from held-out scores. Compare legacy hybrid/connected, opt-in grounded flat and grounded native Relate. Match embedding bytes, 1600-character embedding inputs, eligibility, k=6, RRF=60, cosine=.30, deterministic qualified-identity ties, and 8000-byte/6000-character budgets. Legacy omissions/truncation/lifecycle differences are recorded as policy changes, not a database speed gain. Grounded flat/native use identical application rendering and contracts. Explicit verification requirements are applied to both grounded profiles; legacy does not implement that request contract and is reported unsupported on that track.

The grounded profile is intended to preserve complete source passages, reserve ranked records ahead of optional neighbors, and distinguish retrieval from satisfaction of explicit requirements. Missing verification is unknown, never inferred from a commit message, digest or similarity. No automatic promotion or new approval channel. The native projection derives from one canonical export; it does not own feedback truth.

## Measurement and decision

Three measured warm repetitions after one warm-up, randomized/counterbalanced arm order (seed in settings). Publish all outputs, actual delivered passages, citations, complete bytes/characters, errors, raw times, p50/p95 descriptive only (small samples), peak process RSS and import/refresh time. Inference is included. No exact target tokenizer or agent outcome claims. No native adoption unless correctness gates all pass and quality is within the registered 3 percentage point margin; labels still require human review. No superiority claims, architecture replacement, code removal or merge in this milestone.

Real-Relate gates cover supported capture, update, feedback, supersession, retraction, replay, restart, expiry, foreign bridges, invisible influence, complete conflicts and required records, bounded output, failed build/publication, and corrupt projection detection. Fault injection demonstrates application handling only. Single local owner/writer; no M4 authentication, broker/kernel or remote server work.

Actual generative-agent trials require an authorized endpoint/host and exact model identity. Without these, preserve the paired trial harness and mark NOT RUN; deterministic scripts are not agent trials.
